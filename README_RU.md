# dbt.yu — Telegram Mini App, версия 02

Готовое приложение с каталогом, пятью рубриками, поиском, фильтрами, избранным и списком частей историй. Стиль: дымчато-серые полупрозрачные панели, чёрно-белые бумажные коллажи и красные акценты. На телефоне появляется нижняя панель навигации.

## Что сейчас внутри

Сохранены демонстрационные записи из первой версии: rainy days, golden brown, in another life и другие. Это примеры, а не реальные публикации канала. В них нет ссылок, поэтому части подписаны «скоро» и не открываются. У AU части нумеруются автоматически: `pt. 01`, `pt. 02`, `pt. 03`.

Работают поиск по названиям и описаниям, фильтры по рубрикам и статусам, избранное. Отметки о прочтении доступны для частей с заполненной ссылкой. Закладки и прогресс хранятся только в текущем браузере; между устройствами они не синхронизируются. Если браузер запрещает сохранение, приложение сообщает об этом и сохраняет выбор в памяти до закрытия страницы.

## 1. Посмотреть приложение

После распаковки открой `index.html` в браузере. Для предсказуемой работы локального хранилища можно запустить в этой папке:

```sh
python -m http.server 8000
```

Адрес: http://localhost:8000. Если команда `python` не работает, попробуй `python3`.

## 2. Добавить свои материалы

Открой `data.js` в текстовом редакторе. Здесь находится всё содержание; сервер и установка пакетов не требуются.

- `title`, `subtitle`, `intro` — название, подпись и вступление.
- `channelUrl` — настоящая HTTPS-ссылка на канал. Пока поле пустое, переход в канал скрыт.
- `demo` — оставь `true`, пока используешь примеры. После замены примеров на настоящие публикации поставь `false`.
- `sections` — рубрики. `id` должен быть уникальным и оставаться постоянным.
- `items` — записи рубрики. У каждой записи свой постоянный `id`.
- `chapters` — части работы, в нужном порядке.
- `url` — HTTPS-ссылка на конкретный пост. При пустой ссылке переход недоступен.

Пример записи в рубрике `au`:

```js
{
  id: 'my-au',
  title: 'Название твоего AU',
  kind: 'alternate universe',
  description: 'Краткое описание истории.',
  tag: 'ongoing',
  chapters: [
    { id: 'part-1', title: 'pt. 01', url: 'https://t.me/USERNAME/123' },
    { id: 'part-2', title: 'pt. 02', url: 'https://t.me/USERNAME/124' }
  ]
}
```

Заменяй `USERNAME` и номера постов на настоящие. Для стабильного прогресса после перестановки частей задавай каждой части свой `id`, как в примере. Если его нет, приложение использует порядковый номер.

Статусы: `ongoing` — в процессе; `archive` — в архиве; `fragment` — фрагмент; `spoiler` — спойлер; `answered` — ответ.

Для отдельной публикации без частей укажи `url` прямо внутри записи вместо массива `chapters`. Настоящие ссылки на закрытые каналы доступны только читателям с доступом к этим каналам.

## 3. Разместить по HTTPS

В предоставленной здесь опубликованной версии доступ изначально личный: она предназначена для просмотра владельцем. Перед запуском для читателей потребуется публичный доступ к приложению. Можно изменить доступ к готовому сайту отдельно или разместить файлы на своём HTTPS-хостинге.

Один вариант — GitHub Pages:

1. Создай репозиторий в своём GitHub. Для бесплатного варианта Pages можно использовать публичный репозиторий.
2. Загрузи содержимое распакованного архива: `index.html`, `style.css`, `app.js`, `data.js` и папку `assets` со всеми SVG. `index.html` должен лежать в корне, а не внутри лишней папки.
3. Открой **Settings → Pages**.
4. В **Build and deployment → Source** выбери **Deploy from a branch**.
5. Выбери ветку с файлами, обычно **main**, папку **/(root)** и нажми **Save**.
6. После публикации скопируй показанную GitHub HTTPS-ссылку. Обычно она имеет вид `https://USERNAME.github.io/REPOSITORY/`.
7. Открой адрес с телефона и проверь рубрики и ссылки на реальные посты.

Пароли и токен Telegram-бота для этого приложения не нужны; не добавляй их в файлы сайта.

## 4. Подключить Telegram

1. В Telegram открой https://t.me/BotFather. Если бота ещё нет, создай его командой `/newbot`.
2. Для кнопки в диалоге с ботом отправь BotFather `/setmenubutton`.
3. Выбери бота, укажи подпись кнопки, например «Архив», и публичную HTTPS-ссылку приложения.
4. Открой диалог с ботом и нажми кнопку. Приложение должно открыться внутри Telegram.
5. Чтобы запускать архив прямой ссылкой из канала, настрой в BotFather **Main Mini App** для этого бота и укажи ту же HTTPS-ссылку. После настройки главного приложения используется ссылка `https://t.me/BOT_USERNAME?startapp`.
6. Размести настоящую ссылку на бота с `?startapp` в закреплённом сообщении канала.

Пункты меню BotFather могут различаться по клиентам. Обычная ссылка на сайт в канале может открываться в браузере Telegram; ссылка на настроенное Main Mini App запускает приложение как Mini App. Развёртывание сайта само по себе не создаёт бота и не настраивает его профиль.

Приложение подключает официальный Telegram Web App SDK, адаптирует отступы для безопасной области, использует нативную кнопку «Назад» и открывает ссылки `t.me` через Telegram, когда запущено как Mini App. В обычном браузере ссылки работают как стандартные HTTPS-переходы. Профиль пользователя не запрашивается и на сервер не передаётся.

## 5. Обновления

Измени `data.js` и загрузи его на тот же хостинг вместо предыдущего файла. При изменении оформления обновляй `style.css`, при изменении логики — `app.js`. После развёртывания перезапусти приложение. Когда наполнение станет настоящим, переключи `demo: false`.

## Состав архива

- `index.html` — страница приложения.
- `style.css` — оформление и мобильная адаптация.
- `app.js` — каталог, поиск, избранное, прогресс и Telegram-интеграция.
- `data.js` — редактируемое содержание.
- `assets/` — собственные SVG-коллаж, текстура и иконка.
- `README_RU.md` — эта инструкция.

Сборка не нужна. Сторонних шрифтов и фотографий нет: коллаж нарисован в SVG, используются системные шрифты. Для первичной загрузки Telegram SDK нужен интернет; сайт сохраняет основную функциональность и без SDK.
